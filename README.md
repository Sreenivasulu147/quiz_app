# 🧠 Python Quiz App with Timer (Tkinter)

This is a simple desktop quiz application built using Python's `tkinter` library. It loads questions from a JSON file and presents them with a 10-second timer per question.

---

## 🚀 Features

- GUI built using `tkinter` (no web browser needed)
- 10-second countdown timer for each question
- Multiple-choice questions loaded from a JSON file
- Automatically moves to the next question if time runs out
- Score display at the end of the quiz
- Styled with a clean MIUI (Redmi)-like theme
